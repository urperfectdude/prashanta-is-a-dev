## Overview

At Driveo Electric, I focused on building intelligent internal tools and
customer-facing dashboards to optimize EV fleet management and data
accessibility.

## Key Contributions

- **Fleet Downtime**: Built the real-time monitoring dashboard and ML alerts for
  battery health and range, so fleet operators stopped finding out about
  problems after the fact. Vehicle downtime dropped **30%** and issues got
  resolved 50% faster.
- **Usage Data**: Added product analytics to eight flows so decisions about what
  to build next came from how people used the product, not guesses.
- **Data Access**: Led an AI-powered SQL interface and a real-time LLM assistant
  so people could get answers from the data without writing queries themselves.
- **Fleet Financing**: Banks had no way to underwrite EV fleet loans because the
  risk data sat in our dashboards. Built CredOps to turn fleet telemetry into a
  credit report an underwriter can read like a CIBIL score.
- **Scaling**: Re-architected core data pipelines and optimized search so the
  platform handled **3x traffic growth**.
